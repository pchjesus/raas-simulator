# v6 후속 — 교육 콘텐츠·정보 순서 계약

기준 `f4bbd9f41b84b6ac459bab5009050990558c1cff`, base `feat/learning-experience-v6`, 후속 `feat/v6-learning-content-ia`. 네이비 P1/T1 및 Universal v1.3/ORIGIN-001을 시각 기준으로 유지한다. 외부 탐구 도구의 색·제어판·버튼 외형은 사용하지 않는다. PhET/LOOPY 공식 사이트 읽기는 환경에서 403으로 차단되어 실제 자료를 검토했다고 주장하지 않는다. 구현은 사용자가 명시한 질문→기전 추적→관찰 근거→해석 계약을 따른다.

## 화면·상태 계약

- 안내형: 단원/위치 → 항목별 질문 → 필요한 전후 기전 → 기존 핵심 설명 → 현재 활동/확인 근거/해석 → 기존 간호 → 근거/다음. 9단계 전체 경로는 펼치기로 보존. 자유 탐색 선택 메뉴는 즉시 사용 가능하며 안내형의 중복 메뉴는 숨긴다.
- 시뮬레이터: 현재 조회/진행/최대 도달/적용 약물 → 원본 Canvas(모바일은 기존 카드/Canvas 선택) → 기존 조작 → 현재 기전 → 4변수 결과 → 기존 비교 그래프. 전체 계산 분해는 펼치기로 보존. 수치 불변이 기전 부재를 의미하지 않음을 표시.
- ACEi: 기존 예상→확정→관찰 게이트 후 같은 단계의 무약물/ACEi 결과와 차이를 제시. stage 축과 고정 가정/비임상 한계 명시.
- 임상: 현재 환자 → 판단 → 선택 해설 → 간호 → 기존 게이트 이후 Lab → 디브리핑. 사정/보고/교육은 기본 공개, 문헌은 선택 공개.

`stageData`, `drugData`, `clinicalStageNotes`, `clinicalDrugNotes`는 불변. 새 매핑은 질문·선행 인덱스·읽기 활동·근거 확인 지시만 소유하며 수치/점수/채점 없음. 엔진·임상 상태 대입 없음. 재배치는 기존 DOM 노드/ID/이벤트를 유지한다. 계산식·Canvas 좌표·그래프 및 RAM 수명 불변. 추가 시뮬레이션/자동 조작을 만들지 않는다.

## 16항목 매핑

공통 원본: S[i]=stageData[i]+clinicalStageNotes[i], D[id]=drugData[id]+clinicalDrugNotes[id]. 표시 근거/간호/문헌 ID는 해당 원본에서 읽는다. 아래 질문·활동은 비채점 읽기/설명 과제다.

| 항목 | 핵심 질문 | 선행·관련 | 학습 행동 / 확인 근거 | 해석·간호·출처 |
|---|---|---|---|---|
| 1 혈압 감소 | 어떤 신호가 레닌 분비로 이어질까? | 관류→Renin | 관류/NaCl/β1 신호 찾기 | S[0], [1][4] |
| 2 Renin | 레닌은 무엇을 무엇으로 바꿀까? | 활성 조건→Ang I | 안지오텐시노겐 절단 관계 추적 | S[1], [1][3] |
| 3 Ang I | 전구체와 작용 물질은 어떻게 다를까? | Renin→ACE | Ang I/II 구분 | S[2], [1] |
| 4 ACE | ACE는 어느 전환을 매개할까? | Ang I→Ang II | 효소/기질/생성물 찾기 | S[3], [1][2][3] |

| 6 AT1 | 생성 억제와 수용체 차단은 어떻게 다를까? | Ang II→수용체 | ARB와 ACEi 위치 비교 | S[5], [1][2] |
| 7 Aldosterone | 호르몬 분비와 수용체 작용은 어떻게 연결될까? | Ang II, 원위 네프론 | Na 보유/K 배설·MRA 구분 | S[6], [1][2][3] |

| 12 MRA | 알도스테론 생성과 작용 억제는 어떻게 다를까? | 원위 네프론/MR | 수용체와 K/신기능 감시 연결 | D[aldo], [3] |
| 13 β blocker | 레닌 감소는 어떤 β 작용과 관련될까? | β1→JG cell | RAAS 관련 작용/기타 심장 작용 구분 | D[beta], [1][3] |
| 14 Loop | NKCC2 억제는 어디에서 일어날까? | 굵은 상행각 | RAAS 직접 차단과 구분, 감시 자료 읽기 | D[loop], [3][4] |
| 15 Thiazide | NCC 억제는 Loop와 어디가 다를까? | 원위곡세뇨관 | 표적 위치와 전해질 감시 비교 | D[thiazide], [3][4] |

약물 실제 표적 설명은 기존 `visualization.mechanism`/clinicalDrugNotes를 사용한다. `blockStep`은 그림상 연관 위치, `suppressedRaasSteps`는 계산 기여 규칙이며 약리학적 경로 완전 차단을 의미하지 않는다. Ang II는 단일 직렬 작용이 아닌 기존 clinicalStageNotes[4]의 복수 작용을 표시한다.
