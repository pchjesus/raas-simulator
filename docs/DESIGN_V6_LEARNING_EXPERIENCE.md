## 화면과 상태

허브 → 안내형 학습(기존 5단원/16항목) → ACEi 예상/관찰 → 임상 사례 → 관련 학습 → 원래 임상 기록.
상단 홈/기존 3영역 직접 이동은 항상 제공한다. 데스크톱은 도식과 설명을 인접 배치하고 모바일은 도식 다음 설명 순으로 쌓는다.

```text
홈: 목표 / RAAS 흐름 / 학습 시작 / 시뮬레이터 / 임상 사례
학습: 현재 목표 / 9단계 도식·작용 위치 / 기존 핵심 설명·간호 / 현재 행동 / 다음 항목
실습: 예상 선택 → 확정 → 단계별 비교 관찰 → 해석·기존 간호 자료
임상: 사전 브리핑 → 기존 핵심 정보 → 판단 → 간호 → 조건부 Lab → 기존 복습
```

| 상태 소유자 | 유지/초기화 계약 |
|---|---|
| 기존 state/physiology | 기존 명시적 초기화만 변경; 학습·실습에서 쓰기 금지 |
| 기존 learningCoursePosition/선택 | 기존 16항목·자유 탐색·임상 복귀 유지 |
| 기존 scenarioRuntime/행동/feedback | 홈/탭/튜토리얼에서 수정 금지; 기존 명시적 사례 행동만 초기화 |
| tutorial | 표시 영역/스크롤/포커스만 임시 변경 후 복귀; 자동 시연 중에는 시작하지 않음 |
| practice | 예상/확정/관찰 단계만 소유; calculatePhysiologyAtStep 재사용; 재시작은 실습만 초기화 |

영속 저장 없음. 기존 Canvas 900×380, 그래프 1000×290와 모든 데이터/계산은 보존한다. 대안인 별도 앱/엔진 복제보다 단일 HTML 내부의 명시적 UI 어댑터를 선택한다. 모델 분리는 이 변경에 불필요하며 향후 독립 모듈 전환은 보류한다.

## 위험과 검증

탭 표시 누락→기존 기능 접근 회귀: 기존 3탭 + 현재 브라우저 회귀. 투어 조작→상태 변경: 전후 상태 비교/포커스/ESC/누락 대상/리사이즈. 실습→메인 오염: 모든 단계에서 순수 계산과 메인 상태 비교. 임상 재배치→정답 누출: 기존 공개 함수를 변경하지 않고 두 사례 전체 브라우저 검사. FAST 문법/새 데이터 불변 검사, FOCUSED 새 UX 브라우저, 최종 FULL 역사적 전 스위트 및 기존 브라우저.
