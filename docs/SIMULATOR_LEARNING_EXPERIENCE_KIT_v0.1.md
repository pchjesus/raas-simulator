# Simulator Learning Experience Kit v0.1

설계 및 컴포넌트 계약 초안. RAAS v6.0 후보에서 구현한 패턴이며 Cardiac/Ventilator 이식·학습 효과 검증을 뜻하지 않는다.

## 인터페이스

| 구성 | 입력 | 출력/이벤트 | 금지 |
|---|---|---|---|
| 시작 화면 | 목표·진입 경로 | start / explore / clinical | 진입 시 엔진 초기화 |
| 학습 항목 | id, objective, source-backed content, diagram anchor, action | 이전/다음, 자유 탐색 | 별도 복제 콘텐츠/모델 |
| 화면 투어 | mode, target, title, text | 이전/다음/건너뛰기/닫기 | 실제 조작·저장 실행 |
| 예측 활동 | guess, confirmed, observing, step | confirm / observe / restart | 채점/임상 결과로 재사용 |
| 관찰 어댑터 | 기존 순수 엔진의 입력 | 단위·조건을 가진 비교 결과 | 공통 생리 엔진 신설 |
| 임상 연결 | 기존 사례/질문/답안/공개 게이트 | 관련 개념 방문·동일 세션 복귀 | 답안 삭제·Lab 선공개 |

투어는 실제 DOM 좌표를 추적하고 대상 부재 시 설명만 제공한다. 취소 시 영역·스크롤·초점을 복귀하며 이전 inert 상태를 보존한다. 자동 시연 중에는 정지 후 진입을 안내한다. 원래 엔진을 멈추거나 진행시키지 않는다.

## 화면 규칙

목표 → 학습 대상 도식 → 짧은 핵심 설명 → 현재 행동 → 관찰/해석 → 간호·검사 연결 → 근거/다음 학습. 핵심 안전/단위/데이터 의미는 항상 표시한다. 근거와 심화는 선택 공개 가능하다. 현재 선택/최대 진행/약물 작용은 문자로도 구분한다.

네이비·중립 표면·얇은 경계, 본문 16px/보조 14px를 시작점으로 삼는다. 320/360/390/430px에서 내용 손실 없이 재배치한다. 큰 원본 도식은 축소 대신 별도 가로 탐색을 제공한다. 키보드·Escape·focus trap/복귀·터치 목표·reduced motion을 검증한다.

## 상태 계약과 적용 제외

뷰/튜토리얼/실습은 엔진/임상 상태와 별도로 소유한다. RAM 수명은 새로고침까지이며 영속 저장 도입은 별도 결정이다. 실습 reset은 실습만 초기화한다. 중단·재진입 시 관찰 상태를 유지한다.

RAAS 계산, Cardiac 시간·전기/기계 동기화, Ventilator pending/accept/cancel 및 장비 설정은 각 프로젝트의 소유다. 실시간 장비 설정·실환자 데이터·권한/발행·시간 엔진 제어는 본 키트 적용 범위 밖이다. 현재 RAAS의 16항목은 기존 자료를 재사용하며 예측 활동은 ACEi 한 항목만 제공한다. 다른 활동은 출처/학습 목표/관찰 어댑터/상태 격리 검증 후 추가한다.

## 검증 계약

전후 엔진·세션 스냅샷 동일, 명시적 reset 범위, 공개 게이트, 모든 기존 경로 접근, 실제 DOM 투어/부재/리사이즈/스크롤/키보드, 실제 엔진 결과 비교를 검사한다. 자동 브라우저와 실기기/스크린리더/전문가/학생 검증 결과를 분리한다.

## 교육 콘텐츠 IA 적용 계약 (v6 후속)

항목별 입력은 `question`, `prerequisite`, `action`, `evidence`, `reflect`의 비채점 안내와 기존 원본 콘텐츠 참조다. 개념 확인/기전 추적/인과 설명/약물 비교/실습/임상 종합 중 필요한 유형을 사용한다. 모든 항목에 동일한 퀴즈·시뮬레이션을 강제하지 않는다. 새 점수·숙달 판정과 미구현 실험을 생성하지 않는다.

단원·위치 → 질문 → 현재 관련 기전 → 원본 설명 → 활동·확인 근거·간단한 해석 → 간호 → 문헌/다음 순서를 적용한다. 전체 경로와 계산 분해는 선택 공개할 수 있으나 현재값/단위/모델 의미/필수 간호 안전은 기본 흐름에 둔다. 선택 공개는 기존 DOM 노드를 이동해 원본/이벤트/키보드 접근을 보존한다.

그림상 연관 위치, 실제 약물 표적, 계산 기여 규칙을 서로 다른 의미로 표시한다. 약물 실제 표적은 기존 임상·약물 설명에서 읽으며 `suppressedRaasSteps`를 약리학적 직접 차단 위치로 사용하지 않는다. RAAS 16항목 매핑과 수용 검사는 `DESIGN_V6_CONTENT_IA.md` 및 `tests/browser-content-ia.cjs`를 참조한다.
