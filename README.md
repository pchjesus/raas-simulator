# RAAS Simulator

RAAS(Renin-Angiotensin-Aldosterone System)를 단계적으로 시각화하고, 약물 개입에 따른 생리적 변화를 학습하기 위한 교육용 웹 시뮬레이터.

## 1. 프로젝트 목적

RAAS의 기본적인 생리적 흐름을 시각적으로 이해하고, 주요 약물이 RAAS의 어느 위치에서 작용하는지 확인할 수 있도록 제작되었다.

현재 시뮬레이터는 다음 요소를 포함한다.

* RAAS 단계별 진행
* 이전 단계 탐색
* 약물 작용 위치 표시
* 약물 적용 및 제거
* 혈압, Na⁺, 혈액량, GFR 변화 표시
* RAAS 영향과 약물 영향을 분리하여 표시
* 현재 단계와 진행 완료 단계의 분리 관리
* 화면을 유지하면서 열 수 있는 모달 사용 설명서
* Canvas 단계 클릭 및 키보드 탐색으로 학습 설명 조회

본 프로젝트는 의학·간호학 학습을 위한 교육용 시뮬레이터이며, 실제 환자의 진단이나 치료 결정을 위한 의료기기가 아니다.

## 4. 주요 기능

### 4.1 RAAS 단계 진행

다음 순서로 RAAS를 진행한다.

```text
혈압 감소
↓
Renin
↓
Angiotensin I
↓
ACE
↓
Angiotensin II
↓
AT1 receptor
↓
Aldosterone
↓
Na⁺ / Water
↓
혈압 회복
```

사용자는 다음 단계 버튼을 이용하여 순서대로 진행할 수 있으며, 이전 단계 버튼으로 현재 표시 위치를 되돌릴 수 있다.

---

### 4.2 약물 시스템

현재 지원하는 약물은 6종이다.

1. ACE inhibitor
2. Aldosterone antagonist
3. ARB
4. β blocker
5. Loop diuretic
6. Thiazide diuretic

각 약물은 RAAS의 특정 단계에 작용 위치를 가진다.

약물 적용 시 Canvas에서 해당 작용 위치는 노란색으로 표시된다.

현재 단계가 약물 작용 위치와 동일한 경우에도 **약물 작용 위치의 노란색 표시가 현재 단계의 파란색 표시보다 우선한다.**

---

### 4.3 생리 변수

다음 4개의 생리 변수를 표시한다.

* 혈압
* Na⁺
* 혈액량
* GFR

각 변수는 다음 구조로 계산된다.

```text
기본값
+
RAAS 영향
+
약물 영향
=
현재값
```

화면에서는 기본값, 전체 변화량, RAAS 영향, 약물 영향, 현재값을 확인할 수 있다.

---

### 4.4 사용 설명서 (v4.3.4)

좌측 조작 패널의 **ⓘ 설명서** 아이콘 버튼으로 사용 설명서 모달을 연다. **▤ 패치 내역** 아이콘 버튼은 버전별 변경 사항 팝업을 연다.
조작법, Canvas 색상, 약물 적용·제거, 생리 변수 해석 및 교육용 모델의 한계를 확인할 수 있다.

- 두 팝업 모두 X 버튼, `Esc`, 팝업 바깥 클릭으로 닫는다.
- 내용이 길면 모달 내부에서 스크롤한다.
- 닫히면 사용 설명서 버튼으로 키보드 포커스가 돌아온다.
- 모달 조작은 RAAS 진행 상태, 약물 상태, 생리 계산값을 변경하지 않는다.
- 키보드/모바일 화면의 실제 브라우저 수동 검증은 추가 확인이 필요하다.

---

### 4.5 Canvas 클릭 학습 (v4.4)

9개 RAAS 단계 상자 중 하나를 클릭하면 Canvas 아래에 **단계별 상세 설명 패널**이 나타난다.

- 이름·기본 설명·심화 학습 문구·해당 단계에 설정된 생리 효과·관련 약물을 확인한다.
- 아직 진행하지 않은 단계 또는 현재 적용 약물 이후의 단계도 조회할 수 있다.
- **클릭은 조회 전용**이며 진행 단계, 최대 도달 단계, 약물 적용, 생리 계산값, Canvas 색상에 영향을 주지 않는다.
- 단계 사이의 연결선이나 상자가 아닌 빈 공간을 클릭해도 상태를 변경하지 않는다.
- Canvas에 키보드 포커스를 둔 뒤 방향키·Home·End·Enter·Space로 단계 설명을 열 수 있다.
- 패널의 닫기를 누르면 Canvas로 포커스가 돌아간다.
- Canvas의 내부 좌표, 화면 표시 배율, 테두리 두께를 고려해 클릭 위치를 판정한다.
- 기존 Canvas는 900×380 그대로 유지되며, 상세 패널은 선택 전까지 표시하지 않는다.

실제 브라우저의 좁은 화면 배치, 스크롤·터치 사용성과 키보드 접근성은 별도의 수동 검증이 필요하다.

### 4.6 약물 작용 기전 시각화 (v4.5)

약물 적용 시 기존 노란색 작용 위치 표시 외에 보라색의 **약물별 억제 기전 표식과 설명**을 Canvas의 기존 빈 영역에 표시한다.

- ACE inhibitor: ACE → Angiotensin II 생성 연결 구간의 사선(전환 억제)
- ARB: Angiotensin II → AT1 receptor 작용 연결 구간의 사선(수용체 작용 차단)
- β blocker: Renin 단계 아래 원형 표식(β1 매개 레닌 분비 감소)
- Aldosterone antagonist: Aldosterone 단계 아래 원형 표식(수용체 작용 차단)
- Loop diuretic: Na⁺/Water 단계 아래 원형 표식(실제 표적은 굵은 상행각 NKCC2)
- Thiazide diuretic: Na⁺/Water 단계 아래 원형 표식(실제 표적은 원위곡세뇨관 NCC)

사선과 원형 표식은 교육용 작용 기전을 안내하며 **후속 RAAS 경로의 완전 중단이나 임상적 정량 예측을 의미하지 않는다.** Na⁺/Water 단계는 각 이뇨제의 실제 신세뇨관 작용 부위를 간략히 나타낸 것이다.

**v4.5는 시각화만 추가했다.** `limitStep`, `isStepBlocked()`, `drugAppliedStep`, 기존 진행 제한, 생리 변수 계산식·수치, 약물 6종, v4.4 클릭 학습 동작을 변경하지 않았다. 현재 모델 제약의 근본적인 재설계는 후속 버전의 별도 결정 대상이다. 보라색은 기존 단계 상자 색상 우선순위에 포함되지 않는다.

테스트 재실행: `node tests/regression-v4.5.cjs` (별도 패키지 설치 불필요). v4.4 원본 백업과 v4.5의 상태·생리 계산·단계 클릭·모달·Canvas 호출을 모의 DOM/Canvas 환경에서 비교한다. 실제 브라우저의 픽셀 출력, 레이아웃, 터치, 포커스, 접근성은 별도 검증 필요.

### 4.7 약물 적용 후 단계 탐색과 생리 계산 분리 (v4.6)

- 약물 적용 여부와 관계없이 0~8번의 9개 RAAS 단계를 끝까지 탐색할 수 있다.
- `currentStep`은 현재 탐색 단계, `maxReachedStep`은 실제로 최대 도달한 단계를 뜻한다. 이전 단계 버튼으로 뒤로 돌아가도 생리 변수는 기존 진행 기록(`maxReachedStep`)을 기준으로 계산된다.
- 약물별 `suppressedRaasSteps`에 지정된 단계의 **교육용 RAAS 수치 기여만** 계산에서 제외한다. 이는 후속 생리 경로의 완전 소실이나 약효 100%를 의미하지 않는다.
- ACE inhibitor, ARB, β blocker: 모델상 단계 4·6·7의 RAAS 기여 제외.
- Aldosterone antagonist: 단계 6·7 기여 제외.
- Loop/Thiazide diuretic: 단계 7 기여만 제외.
- 기존 약물의 `physiologyEffect` 정량 값과 4개 변수의 초기값, 9개 단계 순서, 색상과 클릭 학습은 유지한다.
- `drugAppliedStep`은 적용 시점 기록으로 남으며, 현재 약물을 기준으로 기존 진행분의 생리 효과를 재평가한다. **시간·약동학·회복 지연을 모사하지 않는다.**
- `limitStep`은 현재 8로 유지되는 호환성 필드이며 더 이상 다음 단계 버튼을 막는 규칙이 아니다.

모델의 Na⁺ 수치는 실제 혈청 나트륨 농도를 정량 예측하는 것이 아니며, GFR에는 여전히 수치 변화가 적용되지 않는다. RAAS와 약물의 효과를 분리해서 읽기 위한 교육용 가상값이다.

### 4.8 단계별 생리 변화 비교 그래프 (v4.7)

생리 변수 패널 아래에 별도 그래프를 추가한다.

- 혈압(mmHg), Na⁺(mmol/L), 혈액량(%), GFR(mL/min) 중 하나를 선택.
- 파란색은 무약물 RAAS 효과, 보라색 점선은 현재 약물이 적용되었다고 가정한 단계별 계산값.
- X축은 1~9번 RAAS 단계로 **시간축이 아니다**.
- 세로 점선은 `maxReachedStep`을 나타낸다. 그래프 선택은 상태와 현재 생리 계산에 영향이 없다.
- `calculatePhysiologyAtStep()`이라는 동일한 순수 계산 함수를 사용하므로 생리 변수 패널과 다른 독립 공식이 존재하지 않는다.
- 그래프는 전 단계의 **가상 비교**이며 실제 이력을 저장하거나 실제 환자 반응을 예측하지 않는다.

테스트: `node tests/regression-v4.6.cjs`, `node tests/regression-v4.7.cjs`.
기존 v4.5 모델과 수치가 의도적으로 달라졌으므로 이전 v4.5 대비 전체 생리 수치 동일성을 요구하는 테스트는 더 이상 새로운 모델의 기대 결과로 사용하지 않는다.

**실제 브라우저 시각·모바일·클릭 정밀도·접근성 수동 검증은 아직 수행하지 않았다.**

### 4.9 키보드 학습 선택 표시·조작 안내 (v4.7.1)

키보드 탐색에서 설명만 갱신되고 어느 단계가 선택됐는지 상자에 표시되지 않던 문제를 수정했다.

- Tab으로 RAAS 단계 Canvas에 포커스를 놓고 ←/→를 누르면 이전/다음 단계의 상세 설명과 **초록색 테두리·조회 위치 표식**이 함께 갱신된다.
- Home/End는 첫/마지막 단계, Enter/Space는 현재 단계 설명 조회, Esc는 상세 설명 닫기 및 선택 표식 해제.
- 마우스 단계 클릭에서도 동일하게 선택 표시를 갱신하며, 학습 패널의 닫기 버튼으로도 선택 상태를 지우고 Canvas에 포커스를 반환한다.
- 기본 4가지 상자 배경색(노랑·파랑·빨강·회색)은 **시뮬레이션 단계와 약물 상태**를 나타내므로 학습 키보드 탐색으로 바꾸지 않는다.
- 화면 바로 아래에 영구적인 조작 설명을 두어 선택 중인 안내 문구로 덮어쓰지 않도록 했다.
- 보라색 약물 기전 표식의 구형 안내 중 v4.6 이후 모델과 맞지 않던 표현을 정정했다.

학습 조회는 `currentStep`, `maxReachedStep`, 적용 약물, 생리 효과, 그래프 데이터를 변경하지 않는다.
자동 테스트: `node tests/regression-v4.7.1.cjs`. 기존 v4.6/v4.7 회귀 테스트를 함께 확인했다.
실제 브라우저의 시각 표시·키보드 포커스·접근성 및 화면 배율은 아직 수동 검증 필요.

### 4.10 RAAS 경로 시연 (v4.8)

기존 900×380 Canvas에 **교육용 9단계 경로 시연**을 추가했다. 시작 버튼을 누르면 약 850ms 간격으로 1~9단계에 진청색 점선 테두리와 '시연' 표시가 이동한다.

- `▶ 경로 시연`: 첫 단계부터 자동 재생.
- `⏸ 일시정지`: 현재 위치를 유지하고 타이머 중지.
- `▶ 이어보기`: 중단했던 위치부터 다시 재생.
- `■ 시연 종료`: 시연을 끝내고 강조선을 지움.
- 마지막 9단계에서 시연이 종료되며 `▶ 다시 시연`으로 반복 가능.
- 버튼 상태는 `aria-pressed`, 상태 문자열은 `role=status`를 사용한다.

`flowDemo.index`는 **시연 UI에서만 사용하는 값**이다. `currentStep`/`maxReachedStep`, `learningFocusIndex`, 적용 약물, 기존 4개 생리 변수, 생리 변화 그래프에는 영향을 주지 않는다.
기존 단계 배경색과 초록색 학습 조회 선택 마커도 유지한다. 시연 중 실제 진행 및 클릭 학습을 수행해도 서로의 상태가 바뀌지 않는다. 실행 전 외부 패키지는 불필요하다.

검증: `node tests/regression-v4.8.cjs` (171개 결정적 테스트) 및 기존 v4.6/v4.7/v4.7.1 회귀 검증.
v4.8 경로 시연과 기존 주요 기능은 사용자가 실제 브라우저에서 정상 동작한다고 보고했다. 모바일·접근성 전체 검증은 별도 완료된 것으로 간주하지 않는다.

### 4.11 시나리오 데이터·상태 분리 기반 (v4.9)

- 기존 화면, RAAS 9단계, 약물 6종, 생리 변수, 비교 그래프, 학습 선택 및 경로 시연의 사용자 동작은 **변경하지 않았다**.

### 4.13 임상 시나리오 모드 MVP (v5.0)

- 상단 **RAAS 일반 학습 / 임상 시나리오** 버튼으로 독립 화면을 전환한다.
- 첫 사례: **만성콩팥병(CKD)과 알부민뇨가 있는 성인 환자의 ACE 억제제 신규 처방 상황**. 가상 사례이며 개별 실제 검사 수치는 제시하지 않는다.
- 객관식 3문항: 혈압·크레아티닌·K⁺ 추적, 투여 시작/증량 뒤 검사 시기, ACEi·ARB 병용 시 간호 판단.
- **사례 확인 → 선택 → 정답 여부와 근거 해설 → 다음 문항 → 학습 완료/결과 → 다시 풀기** 흐름.
- 시나리오 풀이와 답안은 `scenarioRuntime`에만 저장한다. **일반 학습으로 돌아가면 시나리오 답안은 삭제되고, RAAS 진행·약물·생리 계산·그래프는 유지된다.**
- 시연 중 시나리오 화면으로 이동하면 **타이머가 일시정지되며 위치는 유지**된다. 일반 학습 복귀 후 수동 이어보기가 가능하다.
- 시나리오 기록은 메모리에만 저장되며 새로고침 후 초기화된다.
- `modelPolicy:"reference-only"` 유지. 고정 BP·Na⁺·혈액량·GFR 효과값은 사례 환자의 예상 임상 결과가 아니다.
- 문항의 근거는 KDIGO 2024 CKD Guideline 3.6이다. 원문 링크는 시나리오 화면에 제공한다.
- 실제 진단·투약 결정을 지원하지 않고 간호 사정과 담당 의료진 의사소통을 학습한다.
- 신규 `node tests/regression-v5.0.cjs` 552개, 기존 v4.5~v4.10 포함 4,955개 모의 DOM/Canvas 검사 통과.
- 실제 브라우저·모바일 시각 및 접근성 검증은 보류했다.

### 4.14 선택지별 간호 판단 피드백 및 결과 복습 (v5.1)

- **v5.0에서 구현한 CKD/ACE 억제제 시나리오 1개·3문항을 그대로 유지**하면서 각 문항의 세 선택지마다 별도의 해설(총 9개)을 추가했다.

- 문항당 `nursingFocus` 1개와 선택지당 `feedback` 1개가 정적 교육 콘텐츠로 연결되어 있다. 출처는 기존 `kdigo-2024`를 재사용하며 별도의 임상 예측·투약 처방 판단을 생성하지 않는다.
- 모든 문항을 완료하면 기존 정답 개수에 더해 **문항별 선택/정답/정오표시**를 확인할 수 있다.
- 시나리오 정의 버전은 2로 올렸으며 **스키마 버전 1은 유지**한다. `feedback`·`nursingFocus`는 선택 필드이고, 제공되는 경우 비어 있지 않은 문자열인지 검증한다. 구버전 스키마 1 정의도 정상 처리한다.
- 기존 모드 전환, 풀이 중복 제출 차단, 완료 후 다시 풀기, 메모리 기반 시나리오 상태 및 경로 시연 일시정지 규칙은 유지한다.
- 구형 `tests/regression-v5.0.cjs`는 기존 v5.0 백업을 검사하도록 고정했다. 이전 백업은 수정하지 않았다.

- 아직 실제 브라우저의 시각·키보드·터치 및 모바일 이용 편의성은 사용자가 추후 점검할 예정으로 남겨둔다.

### 4.15 간호 행동 판단 학습 단계 (v5.2)

- 기존 CKD/ACEi 가상 사례의 **3개 임상 판단 문항과 9개 선택지별 설명**을 그대로 유지한다.
- 각 임상 판단의 답변·해설을 확인하면 **다음: 간호 행동 판단** 버튼으로 후속 행동 문제를 연다. 3개 행동 문제에 각각 3개 선택지가 있어 총 9개의 행동 선택지별 해설을 제공한다.
- 권장 학습 순서: **환자 상황 → 임상 판단 선택 → 선택별 근거 확인 → 다음 간호 행동 선택 → 행동별 근거 확인 → 추가 사정/의료진 확인·보고/환자 교육 정리 → 다음 문항 또는 최종 복습**.
- 첫 행동 문제는 ACEi 처방 전후의 기초 혈압·신기능·K⁺ 확인, 둘째는 시작·증량 후 추적검사 계획 확인, 셋째는 ACEi+ARB 병용 가능성의 약물 대조·보고를 다룬다.
- 정답과 오답을 모두 해설하고 행동 선택 뒤 **추가 사정**, **확인·보고**, **환자 교육**의 세 가지 결과를 제공한다. 의학적 상태의 임의 수치 생성이나 처방·투여 변경 결정은 하지 않는다.
- **간호 행동 단계를 완료하지 않은 상태에서 다음 문항 또는 결과 보기를 건너뛸 수 없도록** UI 이벤트를 제한한다. 마지막 임상 판단 답을 제출했더라도 최종 행동 단계를 마쳐야 결과 화면이 나타난다.
- 시나리오 결과는 **임상 판단 정답 3개 중 몇 개**와 **간호 행동 적절한 선택 3개 중 몇 개**를 구분하고, 각 문제의 선택과 권장 선택을 따로 복습한다. 임상 수행능력 인증 목적의 점수가 아니다.
- `SCENARIO_SCHEMA_VERSION=1` 유지, `firstClinicalScenario.version=3`. 문항별 선택적 `actionExercise` 데이터에 문제·선택지·정답·개별 해설·참고문헌 및 추가 사정·보고·교육을 저장한다.
- `scenarioActionPhase`와 `scenarioActionAnswers`는 임상 행동 화면 전용 일시 상태이며 기존 시나리오 정답 기록 `scenarioRuntime.session.answers`와 분리한다. 재시작·종료·모드 전환 시 행동 기록도 초기화한다.
- 교육 근거: KDIGO 2024 CKD Guideline, Practice Point 3.6.2 및 Recommendation 3.6.4. 후속 행동은 간호 교육 예시로서 환자 상태·기관 절차에 따라 달라질 수 있다.
- 신규 `node tests/regression-v5.2.cjs` 모의 DOM/Canvas **728항목**, 과거 버전 포함 총 **6,387항목**의 자동 검사 통과.
- 사용자는 실제 브라우저의 화면·모바일·접근성 검증을 추후 수행한다. 자동 검사만으로 해당 사항의 검증 완료를 주장하지 않는다.

### 4.16 두 번째 임상 사례와 사례 선택 카드 (v5.3)

- 상단 **임상 시나리오** 모드로 들어가면 곧바로 문제를 시작하지 않고 **사례 1 / 사례 2 선택 카드**가 표시된다. 카드는 HTML 버튼으로 키보드·포커스 제어가 가능하다.
- **사례 1: CKD 환자와 ACE 억제제**, 기존 임상 판단 3문항 + 간호 행동 3문항. KDIGO 2024 CKD 지침에 근거한다.
- **사례 2: 증상이 있는 HFrEF 환자와 MRA(스피로놀락톤) 사용**, 임상 판단 2문항 + 간호 행동 2문항. K⁺·신기능 확인과 투여 후 추적검사·환자 교육을 다룬다.
- 사례 2의 출처: **2022 AHA/ACC/HFSA Heart Failure Guideline, §7.3.3**, **NICE NG106 (2025 업데이트) 1.7.3–1.7.5**. AHA의 HFrEF MRA 초기 사용 조건(eGFR >30 mL/min/1.73 m², 혈청 K⁺ <5.0 mEq/L) 및 NICE의 MRA 시작·증량 후 1~2주 신기능·전해질 검사 권고를 근거로 한다. 투약 결정은 사용자가 내리지 않는다.
- 첫 화면의 **다른 사례 선택**으로 현재 사례 세션을 종료하고 목록으로 복귀한다. 종료·일반 모드 이동·다시 진입 시 임상 답안과 간호 행동 기록을 초기화한다. 사례를 풀고 있을 때 카드를 곧바로 누를 수 없게 숨겨 실수로 풀이를 교체할 위험을 줄인다.
- 사례 선택 과정은 `scenarioCaseRegistry`의 정적 정의에 한정되며, 이름만 다른 잘못된 ID의 진입을 거부한다. 새 데이터를 입력받는 기능은 구현하지 않았다.
- 문항·행동 선택, 피드백, 재시작, 최종 결과 화면은 v5.2 공통 엔진을 재사용한다. 각 사례에 따라 3+3 또는 2+2문항과 결과 개수가 자동 표시된다.
- 화면 하단의 **근거 링크는 선택한 사례마다 전환**된다. CKD는 KDIGO, HFrEF는 AHA/ACC/HFSA·NICE 두 가지 원문으로 연결된다.
- 기존 일반 RAAS 학습의 9단계·약물 6종·생리 계산·Canvas·그래프·시연·설명서 팝업은 수정하지 않았다. 시연 중 임상 모드로 진입하면 시연 타이머를 일시정지한다.
- `tests/regression-v5.3.cjs`: 신규 **968개**, 전체 v4.5~v5.3 **7,355개** 결정적 모의 DOM/Canvas 테스트 통과.
- 실제 브라우저/모바일 터치·레이아웃·접근성 수동 검증은 추후 진행한다.

### 4.17 학습 단계·해설 정보 계층화 (v5.4)

- 시나리오 카드에서 **학습 주제 / 임상 판단 문항 수 / 간호 행동 문항 수 / 사례 시작 안내**를 구분했다. 선택한 뒤에는 현재 사례명을 표시하고 카탈로그를 숨기는 기존 전환 정책을 유지한다.
- 풀이 중 `scenarioLearningProgress`에 **현재 임상 판단 선택·해설 / 간호 행동 선택·해설 / 학습 완료** 단계와 임상 판단 및 간호 행동의 완료·남은 수를 함께 표시한다. 이 값은 기존 `scenarioRuntime.session.answers` 및 `scenarioActionAnswers`에서 파생하며 새로운 채점·저장 상태가 아니다.
- 지식 해설은 선택·정답·근거·간호 핵심·출처를 구분한다. 간호 행동 해설의 **추가 사정, 확인·보고, 환자 교육**은 각각 제목과 내용을 가진 영역으로 구성해 동일한 교육 텍스트를 더 쉽게 읽도록 했다.
- 모바일 600px 이하에서는 사례 카드·간호 해설을 한 열로 배치하고, 시나리오 동작 버튼을 화면 폭에 맞춰 배치하며 최소 높이 44px을 지정했다. 일반 RAAS의 900px Canvas 및 기존 모드의 폭·가로 스크롤 동작은 이번 패치에서 변경하지 않는다.
- 단계별 긴 RAAS 심화 설명의 탭/아코디언 전환은 아직 구현하지 않았으며 중요한 UX 선택으로 남긴다. 실제 데스크톱·모바일 브라우저의 레이아웃·터치·키보드/스크린리더 검증 역시 미완료다.
- 역사적 `tests/regression-v5.3.cjs`는 동결 백업 `backups/v5.3.html`을 대상으로 고정했다. 신규 `tests/regression-v5.4.cjs` **804항목**을 추가하여 기존 **7,355항목**과 함께 **총 8,159항목**을 V8/메모리 파일 어댑터·모의 DOM/Canvas에서 재검증했다.

### 4.18 RAAS 단계별 상세 설명 아코디언 (v5.4.1)

- 상위 메뉴: **① 시뮬레이터** (기존 9단계 Canvas·6종 약물·생리 변수·그래프·시연), **② 학습** (기존 단계·약물 설명의 읽기 전용 재배열), **③ 임상 적용** (CKD/ACEi, HFrEF/MRA 사례).

- 완료된 사례의 ‘ⓘ 핵심 임상 포인트 요약 보기’는 별도 모달로 추가 사정, 확인·보고, 환자 교육, 사례 참고문헌을 표시한다. 명시적 닫기·Esc·바깥 클릭 후 실행 버튼으로 포커스가 돌아간다. 원래 두 사례의 교육 목표를 간추린 읽기 전용 요약이며 새로운 의학적 처방을 생성하지 않는다.

- 탭 이동은 `scenarioRuntime`, `scenarioLatestFeedback`, `scenarioActionPhase`, `scenarioActionAnswers`를 유지한다. **다시 풀기 / 다른 사례 선택 / 학습 종료**가 명시적 초기화이며 새로고침 시 세션을 저장하지 않는다. 시연이 실행 중인 시뮬레이터를 벗어나면 일시정지하고 상태는 보존한다.

## 5. Canvas 색상 의미

| 색상  | 의미               |
| --- | ---------------- |
| 회색  | 아직 진행되지 않은 단계    |
| 빨간색 | 실제로 진행이 완료된 단계   |
| 파란색 | 현재 사용자가 보고 있는 단계 |
| 노란색 | 적용된 약물의 작용 위치    |

색상 우선순위는 다음과 같다.

```text
노란색(약물 작용 위치)
>
파란색(현재 단계)
>
빨간색(진행 완료)
>
회색(미진행)
```

단, 이 우선순위는 현재 Canvas 표시를 위한 시각적 규칙이며, 생리 계산 로직과 동일한 개념은 아니다.

## 6. 현재 구조의 핵심 개념

### state.progress.currentStep

사용자가 현재 보고 있는 단계를 의미한다.

### state.progress.maxReachedStep

사용자가 실제로 진행하여 도달한 가장 높은 단계를 의미한다.

따라서 사용자가 이전 단계로 이동하더라도 실제 진행 기록은 유지된다.

예:

```text
maxReachedStep = 6
currentStep = 3
```

이 경우 사용자는 3단계를 보고 있지만 0~6단계까지 진행한 기록은 유지된다.

## 7. 현재 생리 모델

현재 모델은 교육용 단순화 모델이다.

RAAS의 주요 단계에 다음과 같은 효과가 연결되어 있다.

```text
Angiotensin II
→ 혈압 증가

Aldosterone
→ Na⁺ 증가
→ 혈액량 증가

Na⁺ / Water
→ 혈압 증가
```

약물은 별도의 약물 효과값을 가지고 있으며, 최종 생리 상태는 RAAS 영향과 약물 영향을 합산하여 계산한다.

## 11. Codex 및 AI 개발 시 원칙

AI가 코드를 수정할 때는 먼저 다음 문서를 확인해야 한다.

```text
README.md
SPEC.md
DEVLOG.md
```

특히 `SPEC.md`의 현재 시스템 규칙을 기존 코드와 함께 확인한 후 수정한다.

기능 추가 또는 구조 변경으로 기존 규칙이 변경될 가능성이 있는 경우, 코드를 바로 수정하기보다 변경의 영향과 회귀 가능성을 먼저 검토한다.

현재 구현되지 않은 기능을 이미 구현된 기능으로 간주해서는 안 된다.

## v5.6–v5.9 교육 플랫폼 통합 개발 (2026-10-14)

- 모바일: 9개 카드로 RAAS 기전을 조회하고, 원래 900px Canvas를 별도 가로 탐색으로 이용한다. 카드 조회는 약물·생리 엔진을 변경하지 않는다.
- 학습: 5개 안내 단원에서 RAAS 9단계와 6개 약물을 순회하거나 자유 탐색할 수 있다. 혈청 K⁺, Cr, eGFR, UACR, 혈압의 의미와 근거 링크가 있다.
- 임상: 기존 CKD/ACEi 3문항과 HFrEF/MRA 2문항의 **정답과 질문을 보존한다**. 문항별 간호 행동을 제출한 뒤 관련되는 경우에만 **별도 추가 평가 시점**의 정적 가상 Lab 예시가 나타난다. ACEi/ARB 중복 처방 문항에는 관련 없는 수치를 제공하지 않는다.
- 복습: 모든 판단·행동 답안이 오답 우선으로 표시되고, 관련 RAAS 단계 및 약물 학습으로 이동했다가 기존 임상 세션을 유지한 채 돌아올 수 있다.
- 주의: RAAS 그래프의 Na⁺/GFR/BP는 임상 환자별 Lab 예측값이 아니다. 앱은 실제 처방·치료 결정 도구가 아니다.
