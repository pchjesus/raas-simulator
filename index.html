RAAS Simulator 사용 설명서

RAAS 경로의 진행, 약물 작용 위치, 생리 변수 변화를 확인하는 교육용 시뮬레이터입니다.

1. 기본 조작

  • 다음 단계: RAAS 경로를 한 단계 진행합니다. 약물을 적용해도 9단계를 모두 탐색할 수 있습니다.
  • 이전 단계: 표시 중인 단계를 한 단계 되돌립니다. 이미 도달한 최대 단계와 생리 효과는 되돌리지 않습니다.
  • 진행 초기화: RAAS 진행 기록만 초기화합니다. 적용된 약물은 그대로 유지됩니다.
  • 전체 초기화: 진행 기록과 적용 약물을 모두 초기화하고 약물 선택창도 ‘약물 없음’으로 되돌립니다.

1-1. 키보드로 단계 학습하기

Tab으로 RAAS 단계 Canvas에 키보드 초점을 맞춘 후 아래 키를 사용합니다. 방향키만으로도 해당 단계의 학습 설명이 열립니다.

  • ← / →: 이전 / 다음 단계의 학습 설명으로 이동합니다.
  • Home / End: 첫 번째 / 마지막 단계로 이동합니다.
  • Enter / Space: 선택 중인 단계의 설명을 열거나 다시 표시합니다.
  • Esc: 열려 있는 학습 설명을 닫고 선택 테두리를 지웁니다.

초록색 테두리와 위쪽 조회 표시는 현재 학습 대상으로 선택한 상자를 알려 줍니다. 노랑·파랑·빨강·회색은 기존 시뮬레이션 진행·약물 상태를 그대로 나타냅니다. 키보드 탐색은 진행·생리 수치를 변경하지 않습니다.

1-2. RAAS 경로 시연

▶ 경로 시연으로 9개 단계의 진행 순서를 자동으로 훑을 수 있습니다. 시연 중 같은 버튼으로 일시정지하고, 다시 눌러 이어봅니다. ■ 시연 종료로 초기화합니다. 끝나면 다시 시연할 수 있습니다.

진청색 점선과 '시연' 표식은 자동 학습용입니다. 기존 초록색 '조회' 선택, 노랑·파랑·빨강·회색 단계 배경, 약물·생리 변수 및 비교 그래프는 바뀌지 않습니다. 시연 중에도 기존 조작을 사용할 수 있습니다.

2. Canvas 색상

빨강: 진행한 단계
파랑: 현재 보고 있는 단계
노랑: 적용 약물의 작용 위치
회색: 아직 진행하지 않은 단계
보라: 약물 작용 기전 표식
초록 테두리: 학습 선택 단계

단계 상자의 색상 우선순위는 노랑 → 파랑 → 빨강 → 회색입니다. 보라색은 약물 작용 기전 안내이며 단계 상자 색상이나 생리 계산값을 바꾸지 않습니다.

3. 약물 적용과 제거

  • 선택창에서 ACE inhibitor, Aldosterone antagonist, ARB, β blocker, Loop diuretic, Thiazide diuretic 중 하나를 고르고 약물 적용을 누릅니다.
  • 약물 작용 위치가 노란색으로 표시되며 생리 변수에 교육용 약물 효과가 반영됩니다.
  • v4.6부터 약물 적용 후에도 마지막 9단계까지 탐색할 수 있습니다. 약물로 억제되는 교육용 RAAS 기여 효과만 제외하고 약물 고정 효과는 별도로 계산합니다.
  • 보라색 사선은 전환·수용체 작용의 억제, 보라색 원형 표식은 특정 표적 작용의 억제를 뜻합니다. 시뮬레이터에서 일부 단계의 수치 기여가 제외되더라도 생리적 경로가 완전히 중단되거나 약효가 100%라는 뜻은 아닙니다. 이뇨제의 신세뇨관 표적은 간략한 Na⁺/Water 단계에 요약해 표시합니다.
  • 약물 제거: 적용 효과와 시뮬레이션의 약물 효과를 해제합니다. 약물 선택창의 선택 항목과 이전 진행 기록은 유지됩니다.

4. 생리 변수 읽는 방법

혈압(BP), Na⁺, 혈액량, GFR의 기본값, 변화량, 현재값을 표시합니다.

현재값 = 기본값 + RAAS 영향 + 약물 영향

  • 혈압: mmHg / Na⁺: mmol/L / 혈액량: 기준값 100% / GFR: mL/min
  • 화살표 ↑·↓는 계산된 변화 방향을 뜻합니다.
  • GFR은 현재 단순화 모델에서 별도의 변화 효과가 없으므로 값이 유지됩니다.
  • Na⁺ 변화량은 혈청 나트륨의 실제 변화를 예측한 값이 아닙니다. 총 체내 Na⁺ 보유량과 혈청 농도는 다르며 K⁺ 역시 이 모델에서는 계산하지 않습니다.

5. 임상 학습 시 확인할 핵심 원칙

RAAS 활성화와 실제 환자 반응은 다릅니다. 신장 관류압 저하·원위세뇨관 NaCl 전달 감소·β1 교감신경 자극이 레닌 분비를 촉진할 수 있습니다. 안지오텐신 II는 혈관수축과 알도스테론 분비에, 알도스테론은 원위 네프론의 Na⁺ 재흡수와 K⁺ 배설에 관여합니다 [1].

  • 환자 사정: 활력징후 추세, 어지럼과 기립성 증상, I/O·소변량·체중·부종, 호흡곤란·폐음, 혈청 전해질·신기능을 함께 평가합니다 [3, 4].
  • ACEi·ARB: 혈압·크레아티닌/eGFR·K⁺ 모니터링은 중요합니다. 만성콩팥병 관련 KDIGO 지침에서는 시작·증량 후 환자 상태에 따라 2~4주 이내 확인하도록 안내합니다 [2]. 실제 검진 주기는 환자·적응증·기관 지침에 따릅니다.
  • MRA: 고칼륨혈증 위험과 신기능을 확인합니다. 심부전 환자의 약물 시작 및 증량 후 검사는 질환별 가이드라인과 처방에 따릅니다 [3].
  • 이뇨제: 저혈압·탈수·저나트륨혈증·저칼륨혈증 등과 체중·소변량 변화를 같이 평가합니다 [4].

7. 세 학습 영역과 임상 적용 (v5.5)

① 시뮬레이터는 RAAS 경로·약물·생리 변화를 조작합니다. ② 학습은 9단계 기전 및 약물 6종의 의학·간호 설명을 정리합니다. ③ 임상 적용은 CKD/ACEi 또는 HFrEF/MRA 사례에서 판단과 행동을 연습합니다.

임상 학습 순서: 환자 파악 → 임상 판단 → 선택한 답/권장 답안 비교·근거 확인 → 간호 행동 → 행동 해설 → 다음 문항 → 완료 복습. 상세 근거는 접이식 영역에서 확인하고, 완료 후 ⓘ 핵심 임상 포인트 버튼으로 별도 팝업을 엽니다.

상단의 탭 이동은 풀이를 보존합니다. 다시 풀기·다른 사례 선택·학습 종료는 답안을 초기화하며, 새로고침 시 풀이 기록은 사라집니다.

7-1. 기존 임상 사례 안내

상단의 임상 시나리오에서 만성콩팥병 환자의 ACE 억제제 관련 3문항을 풀 수 있습니다. 임상 시나리오에 진입하면 CKD·ACE 억제제 또는 HFrEF·MRA 사례를 선택합니다. 풀이 중에는 다른 사례 선택으로 돌아갈 수 있지만 현재 답안은 삭제됩니다. 기존 선택지별 해설을 확인한 뒤 다음: 간호 행동 판단으로 추가 사정·보고·환자 교육에 관한 선택지를 풉니다. 행동 해설을 확인해야 다음 문항으로 이동할 수 있으며 완료 후 지식 판단과 간호 행동의 선택을 각각 복습할 수 있습니다.

일반 학습으로 돌아가면 시나리오의 답안 기록만 초기화하고 RAAS 진행·약물·생리 상태는 보존됩니다. 경로 시연 도중 전환하면 시연을 일시정지합니다. 새로고침 후에도 시나리오 답안은 보존되지 않습니다.

8. 교육용 모델의 한계

시뮬레이터의 약물 및 RAAS 효과값은 교육을 위한 단순화된 수치입니다. 실제 환자의 혈압, 전해질, 혈액량 또는 신기능을 예측하거나 치료 결정을 내리는 데 사용할 수 없습니다.

설명서를 닫으려면 × 버튼이나 Esc 키를 사용하세요. 팝업 바깥을 클릭해도 닫힙니다. 단계별 자세한 의학·간호 내용은 Canvas의 상자를 선택해 확인할 수 있습니다.

v5.4.1 — RAAS 단계별 상세 설명 아코디언

단계 설명을 기전, 간호 사정, 약물·근거 세 영역으로 구분했습니다. 기전은 처음에 열려 있으며 영역을 각각 펼쳐 비교할 수 있습니다. 기존 Canvas 탐색, 약물, 생리 계산, 임상 사례는 그대로 유지합니다.

v5.4 — 임상 시나리오 정보 구조 개선

두 사례의 선택 카드와 풀이 진행 안내를 개선하고, 긴 간호 행동 해설을 추가 사정·보고·환자 교육으로 구분했습니다.

v5.3 — 두 번째 임상 사례와 선택 카드

기존 CKD·ACE 억제제 사례와 새로운 HFrEF·MRA 모니터링 사례를 사례 선택 카드에서 고를 수 있습니다. 새 사례에는 지식 판단 2문항과 간호 행동 2문항을 추가했으며 AHA/ACC/HFSA 2022·NICE NG106(2025) 근거를 연결했습니다. 사례별 답안을 분리하고 다른 사례 선택/종료 시 기록을 초기화합니다. 기존 RAAS 모델은 변경하지 않았습니다.

v5.2 — 간호 행동 판단 단계

첫 CKD/ACEi 사례의 기존 3문항 뒤에 각각 간호 행동 선택 단계를 추가했습니다. 판단 근거 확인 → 실제로 확인·보고·교육할 내용 선택 → 행동별 해설과 추가 사정·보고·교육 요점 확인 → 다음 문항 흐름입니다. 3개 간호 행동 선택의 결과도 복습에 표시합니다.

v5.1 — 선택지별 임상 피드백 강화

첫 사례의 3문항에 9개 선택지별 오개념 해설과 문항별 간호 사정·보고 포인트를 추가했습니다. 각 답변 뒤 선택한 답·정답·공통 근거를 구분하고, 완료 화면에서 자신의 선택을 복습할 수 있습니다. 기존 환자 예측 계산이나 처방 결정 기능은 추가하지 않았습니다.

v5.0 — 첫 임상 시나리오 교육 모드

일반 학습과 분리된 CKD/ACE 억제제 간호 시나리오를 도입했습니다. 3문항, 정답·해설·근거, 학습 결과, 다시 풀기를 제공하며 일반 학습의 진행·생리 계산은 변경하지 않습니다. 시나리오에서 일반 학습으로 돌아가면 답안이 초기화됩니다.

v4.10 — 임상 학습 설명 및 안내 팝업

RAAS 9단계의 의학·간호 설명과 약물 6종의 모니터링 포인트를 보강했습니다. 설명서에 근거와 교육용 모델 한계를 추가하고, 설명서·패치 내역을 각각 아이콘으로 여는 팝업을 구성했습니다. 기존 계산식과 진행·시연 동작은 유지합니다.

v4.9 — 시나리오 구조 기반

시나리오 정의·출처 검증, 독립 세션 상태, 풀이·초기화·종료 함수를 추가했습니다. 실제 임상 사례·시나리오 화면·환자 예측 모델은 아직 구현하지 않았습니다.

v4.8 — RAAS 경로 시연

9개 단계를 자동으로 강조하는 시연, 일시정지·재개·종료·재시연 기능을 추가했습니다. 생리 계산과는 독립적입니다.

v4.7.1 — Canvas 선택 표시 개선

마우스·키보드 학습 선택 단계에 초록색 테두리·조회 표시를 추가했습니다.

v4.7 — 생리 변수 비교 그래프

혈압·Na⁺·혈액량·GFR의 단계별 가상 값을 무약물 및 현재 약물 조건에서 비교하도록 했습니다. X축은 시간이 아닌 RAAS 단계입니다.

v4.6 — 약물과 진행·계산 분리

약물 사용 중에도 9단계를 계속 탐색하고, 약물별 교육용 RAAS 기여만 계산에서 조정하도록 변경했습니다.

v4.5 — 약물 기전 시각화

6종 약물의 작용 위치와 기전 표식을 보라색으로 추가했습니다.

v4.4 — 단계 학습 조회

Canvas 상자를 클릭하거나 키보드로 선택하면 자세한 설명을 조회할 수 있게 했습니다.

v4.3.4 — 모달 사용 설명서

기존 시뮬레이션 상태를 변경하지 않는 사용 설명서를 추가했습니다.

이 프로그램은 의학·간호 교육용이며 실제 진료·투약 결정에 사용하지 않습니다. 새 기능과 이전 기능의 상세 검증 결과는 DEVLOG.md에 기록합니다.
